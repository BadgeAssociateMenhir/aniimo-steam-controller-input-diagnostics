## 🧭 Symptoms Covered

- Steam recognizes the controller but Aniimo does not respond to button presses.
- The controller works in some screens but not gameplay.
- Native controller input conflicts with Steam Input emulation.

## 🛠️ Troubleshooting — Step by Step

1. Confirm controller buttons register in Windows Game Controllers or Steam controller testing.
2. In Steam Library, open Aniimo → Properties → Controller, select Disable Steam Input as the official workaround, then restart the game.
3. Disconnect duplicate controllers and virtual input devices for one clean test.
4. Reconnect the controller and test the in-game menu and gameplay separately.
5. If not resolved, record controller model, wired/Bluetooth connection and input mode when reporting.
